개인정보를 지키는 방법

인터넷을 사용할 때
기본적인 보안 수칙만 지켜도
개인정보를 안전하게 보호할 수 있습니다.

  • 안전한 비밀번호 만들기

    비밀번호는 외부로부터 나의 정보를 지키는 가장 기본적인 수단입니다.
    영문, 숫자, 특수문자를 조합하고 사이트마다 다른 비밀번호를 사용하는 것이 좋습니다.

    TIP

    • 8자 이상, 영문·숫자·특수문자 조합하기

    • 사이트마다 다른 비밀번호 사용하기

    • 주기적으로 비밀번호 변경하기

  • 계정 보안 강화하기

    2단계 인증은 비밀번호가 유출되더라고 추가 인증을
    거쳐야 계정에 접근할 수 있도록 보호 하는 방법입니다.

    TIP

    • 자주 사용하는 계정은 2단계 설정하기

    • 인증번호를 다른 사람에게 알려주지 않기

    • 사용하지 않는 인증 기기는 정리하기

  • 사용 후 흔적 지우기

    PC방, 도서관 등 여러 사람이 사용하는
    컴퓨에서는 로그인 정보가 남아 개인정보가 노출될 수 있습니다.

    TIP

    • 사용 후 반드시 로그아웃하기

    • 비밀번호 자동 저장하지않기

    • 금융·개인정보 관련 서비스는 가급적 이용하지 않기

  • 링크 클릭 전 확인하기

    문자나 이메일에 포함된 출처가
    불분명한 링크는 피싱 사이트나 악성코드로 연결 될 수 있습니다.

    TIP

    • 출처가 불분명한 링크 클릭하지 않기

    • URL 주소가 공식 사이트 인지 확인하기

    • 개인정보나 인증번호 입력 요구 시 주의하기

SNS에서
개인정보를 지키는 방법

SNS에 올리는 작은 정보도
개인정보로 악용될 수 있습니다.

  • 나의 정보 공개 범위 관리

    SNS 게시물은 내가 생각하는 것보다 많은 사람에게 공개될 수 있습니다.
    게시물과 프로필의 공개 범위를 확인해 주세요.

    TIP

    • 게시물 공개 범위 확인하기

    • 모르는 사람의 팔로우 요청 주의하기

    • 연락처와 프로필 정보 과도하게 공개하지 않기

  • 위치정보 노출 줄이기

    사진이나 게시물에는 촬영 장소와 같은 위치정보가 포함될 수 있습니다.
    일상적인 동선이 노출되지 않도록 주의해야 합니다.

    TIP

    • 사진 업로드 전 위치정보 확인하기

    • 실시간 위치를 공개하지 않기

    • 집·학교·직장 등 자주 가는 장소 노출하지 않기

  • 사진 속 개인정보 확인

    사진 한 장에도 이름, 주소, 연락처, 신분증 등
    다양한 개인정보가 포함될 수 있습니다.

    TIP

    • 사진 속 개인정보 확인하기

    • 신분증·명찰·택배 송장 가리기

    • 다른 사람의 사진은 동의 후 게시하기

  • 안전하지 않은 계정 차단

    모르는 계정이 보내는 메시지나 팔로우 요청을 통해
    개인정보를 요구하거나 악성 링크를 전달할 수 있습니다.

    TIP

    • 모르는 계정의 메시지에 응답하지 않기

    • 개인정보 요구 시 바로 차단하기

    • 의심스러운 계정 신고하기

  • 앱 권한 확인하기

    앱은 카메라, 마이크, 위치정보 등 다양한 권한을 요청할 수 있습니다.
    꼭 필요한 권한만 허용하는 것이 좋습니다.

    TIP

    • 앱 설치 후 권한 확인하기

    • 사용하지 않는 권한 끄기

    • 위치정보는 필요한 경우에만 허용하기

  • 스마트폰 잠금 설정하기

    스마트폰을 분실하거나 다른 사람이 접근했을 때
    개인정보가 노출되지 않도록 화면 잠금을 설정해 주세요.

    TIP

    • PIN 또는 비밀번호 설정하기

    • 쉽게 추측할 수 있는 번호 피하기

    • 자동 잠금 시간을 짧게 설정하기

  • 안전한 Wi-Fi 사용하기

    공공장소의 무료 Wi-Fi는 보안이 취약할 수 있어
    개인정보나 금융정보를 입력할 때 주의해야 합니다.

    TIP

    • 출처가 불분명한 Wi-Fi 연결하지 않기

    • 금융거래는 안전한 네트워크에서 이용하기

    • 자동 Wi-Fi 연결 기능 확인하기

  • 스마트폰 최신 상태 유지하기

    스마트폰 운영체제 업데이트에는
    새로운 기능뿐 아니라 보안 취약점을 해결하는 내용도 포함됩니다.

    TIP

    • 최신 업데이트 유지하기

    • 자동 업데이트 설정하기

    • 오래된 기기는 보안 지원 여부 확인하기

    주민등록번호, 주소, 연락처 등이 포함된 문서나 사진은
    다른 사람에게 노출되지 않도록 안전하게 관리해야 합니다.

    TIP

    • 중요한 문서 함부로 공유하지 않기

    • 필요 없는 개인정보 문서 안전하게 폐기하기

    • 클라우드·사진 앨범 접근 권한 확인하기

  • 일상 속 정보 노출 예방하기

    카페나 대중교통처럼 사람이 많은 곳에서는
    화면이나 대화 내용을 통해 개인정보가 노출될 수 있습니다.

    TIP

    • 공공장소에서 개인정보 입력 시 주변 확인하기

    • 중요한 통화는 사람이 적은 곳에서 하기

    • 화면을 다른 사람이 쉽게 볼 수 없도록 주의하기

  • 정보 제공의 기준 세우기

    서비스 이용 중 개인정보를 요구받았다면
    어떤 정보를 왜 수집하는지 확인한 후 제공하는 것이 좋습니다.

    TIP

    • 필요한 정보인지 확인하기

    • 개인정보 이용 목적 확인하기

    • 불필요한 정보는 제공하지 않기
